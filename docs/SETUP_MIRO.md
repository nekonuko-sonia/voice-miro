# Miroトークンの取得（1回だけ・約5分）

Voice-MiroがあなたのMiroボードに付箋を書き込むための「鍵」を作ります。
**無料のMiroアカウントでOK**です。

## 手順

1. ブラウザでMiroにログインした状態で https://developers.miro.com/ を開く
2. 右上の **「Your apps」** → **「Create new app」**
3. アプリ名: `Voice-Miro`（何でもよい）/ チーム: 自分のチームを選択
4. **「Expire token」のチェックを外す**（←重要。非期限トークンになり、以後更新不要）
5. Create app
6. アプリ設定画面の **Permissions（スコープ）** で以下にチェック:
   - `boards:read`
   - `boards:write`
7. 同じ画面の **「Install app and get OAuth token」** をクリック → 自分のチームを選んで **Install**
8. 表示された **アクセストークン**（`eyJtaXJvLm...` みたいな長い文字列）をコピー

## トークンをPCに設定

**Windows**: コマンドプロンプトで
```
setx MIRO_TOKEN "コピーしたトークン"
```
→ 開いているターミナルを閉じて開き直す（start.batもいったん閉じて再実行）

**Mac**: ターミナルで
```
echo 'export MIRO_TOKEN="コピーしたトークン"' >> ~/.zshrc
source ~/.zshrc
```

## 確認

`start.bat` / `start.command` で起動 → 画面上部の **Miro: 🟢** になっていればOK。

## チーム運用（ソニアのアカウントに集約する場合）

- Voice-Miroは**ソニアのMiroトークン1つ**を全員のPCで使う運用にできます（ねこ・ぬこはトークン設定不要）。設定の同梱方法は `配布手順_ソニア用.md`。
- **他の2人がログイン無しでボードを開けるようにするには、Miroを有料プランにする**必要があります。
  - 有料化すると、Voice-Miroが作るボードは自動で「リンクを知っていれば誰でも編集可」になります（コード変更不要。`lib/miro.js` の createBoard が有料プランでのみ通る共有設定を自動適用）。
  - 無料プランのままだと、ボードはソニアのアカウント内に作られ、他2人が見るにはソニアのMiroにログインが必要です。

## 注意

- トークンは**パスワードと同じ扱い**で。公開リポジトリやチャットに貼らない（環境変数 or `config.local.json` にのみ置く）
- トークンで書き込めるのは**そのアカウントがアクセスできるボードだけ**です
- 無料プランは編集可能ボード3枚まで。有料化で解消（`配布手順_ソニア用.md` 参照）
