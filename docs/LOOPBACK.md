# オンラインmtgの相手の声も拾う（ループバック設定）

Zoom/Meet/Discord等で**相手の声**もボードに反映したい場合、PCの再生音をマイク扱いにする「仮想オーディオデバイス」を使います（無料・1回設定すればOK）。

対面セミナーや自分の発話だけで良い場合は、この設定は不要です。

## Windows: VB-CABLE

1. https://vb-audio.com/Cable/ から VB-CABLE をダウンロード → インストール（要再起動）
2. **自分の声と相手の声を両方拾う一番簡単な構成**:
   - Windowsの「サウンド設定」→ 出力を `CABLE Input` に変更
   - サウンドコントロールパネル → 録音タブ → `CABLE Output` のプロパティ → 「聴く」タブ → 「このデバイスを聴く」にチェック＋再生先をスピーカーに（自分にも聞こえるように）
   - Voice-Miroのマイク選択で `CABLE Output` を選ぶ
3. 自分の声も入れたい場合はZoom側のマイクは通常のマイクのままでOK（Zoomの受信音声＝相手の声がCABLEに流れ、あなたの声はZoomが拾って相手側から返ってこないため、**自分の声はマイク、相手の声はCABLE**という2系統になる点に注意）
   - 両方まとめたい場合は「ステレオミキサー」が使えるPCならそちらが簡単（録音タブで有効化→Voice-Miroでステレオミキサーを選択）

## Mac: BlackHole

1. `brew install blackhole-2ch`（または https://existential.audio/blackhole/ ）
2. 「Audio MIDI設定」→ 「複数出力装置」を作成 → `スピーカー` と `BlackHole 2ch` にチェック
3. Macのサウンド出力を今作った複数出力装置に変更（相手の声がスピーカーとBlackHole両方に流れる）
4. Voice-Miroのマイク選択で `BlackHole 2ch` を選ぶ

## コツ

- **まずは対面モード（普通のマイク）で運用に慣れてから**ループバックに進むのがおすすめ
- 会議室で複数人が1つのPCの周りにいる場合は、普通のマイクのままで全員の声が拾えます（話者区別はされず全員分が板書されます）
